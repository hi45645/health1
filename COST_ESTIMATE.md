# Cost estimate

Production costs depend on the selected Indian or regional host, storage policies, tax, traffic, and ongoing clinic communications. Planning ranges below are in INR per month unless stated otherwise. These are budgeting assumptions, not verified provider quotes.

| Item | Planning estimate | Notes |
| --- | ---: | --- |
| Single application host | ₹700–₹2,000 | Includes resources to serve the app |
| SQLite database | Included | Uses the persistent host volume |
| Persistent volume | ₹0–₹500 | Included on some plans, billed separately on others |
| Encrypted off-host backup | ₹50–₹500 | Varies with volume, retention, and recovery traffic |
| Monitoring | ₹0–₹500 | Confirm the production alerting and retention limits |
| Existing domain renewal | ₹1,000–₹2,500/year | Verify the actual renewal quote and transfer cost with the registrar |
| Calls, email, SMS or WhatsApp | Provider-dependent | Budget separately if using a paid provider |

A working estimate for hosting, storage, backup, and monitoring is ₹750–₹3,500 per month before domain renewal, optional messaging, and tax. The website has no paid runtime translation dependency. Compare actual provider quotes, commercial use terms, volume durability, support, quotas and inactivity rules before selecting a plan.
